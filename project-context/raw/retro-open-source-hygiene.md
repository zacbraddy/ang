# Retro follow-ups: open-source hygiene

## PR template is heavy for small fixes
`.github/PULL_REQUEST_TEMPLATE.md` asks every raiser which first principle their change serves, why it isn't a local workflow improvement, and who else benefits. A typo or broken-link fixer gets the same questions. This was a should-fix in story 05's review that wasn't applied.

Idea: add one line saying a small fix only needs to say what it fixes, so the rubber-ducking prompts apply to real changes. Small fixers are probably the most likely outside contributors, so the template shouldn't put them off.
