# Documentation

## Summary
Delivers two release goals from the intent as one unit: a whistle-stop README (concepts, key commands, quick start) and a live docs site in Zac's voice. The README goes first and ships on its own. The site is built on Starlight, hosted on GitHub Pages and deployed by an Actions workflow. Status badges on the README wait on the CI from the separate open-source-hygiene epic.
