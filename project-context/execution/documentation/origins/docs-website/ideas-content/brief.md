# Brief

## Summary
Zac's requirements (2026-11-13) for a comprehensive docs site, kept separate from the short repo README.

## Requirements
- **Design:** clean, fresh, simple, pleasant and functional. Light and dark mode, defaulting to system. No obviously AI-made design.
- **Build:** use an out-of-the-box docs framework, not a from-scratch build. Research what's best in class and widely liked in 2026. Docusaurus is fine if it wins, but not just because it's familiar.
- **Hosting:** a domain plus self-hosting is acceptable, but costs ongoing fees and needs CI/CD. GitHub Pages is untried and appealing if the results are good. Research it.
- **Content:** combine the brain-dump context with an investigation of Ang's files. Keep Zac's voice and the spirit of how he conveys ideas, trimmed where the source is verbose.
- **Attribution:** briefly mention Zac and We Right Code (Ang was developed as part of his work under We Right Code), linking https://zackerthehacker.com. We Right Code has no site yet. Easy to find, not in people's faces.

## Accuracy rule
Where the brain dump describes how Ang works and the framework files differ, the files are the truth: Zac was relaying from memory, not asking for changes. Example: the evidence tiers in `src/project-context/README.md` (Evidence standard) are correct, and the brain dump's version is not.
