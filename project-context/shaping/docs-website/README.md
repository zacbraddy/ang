# Documentation website

## Summary
A full docs site for users who've tried Ang and want to go deeper: usage, concepts, ambitions, motivations. Clean and simple, with light and dark mode following the system setting, using existing tools rather than a from-scratch build. The 2026 docs-framework field is mapped; GitHub Pages' own options are not yet. Hosting is open: GitHub Pages or a domain. Content is in Zac's voice, trimmed, with a brief plug for Zac and We Right Code.

## Why it matters
A live docs site is a release goal in the intent, and Ang has a lot of concepts for a lean framework.
