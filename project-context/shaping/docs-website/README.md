# Documentation website

## Summary
A full docs site for users who've tried Ang and want to go deeper: usage, concepts, ambitions, motivations. Clean and simple, with light and dark mode following the system setting, using existing tools rather than a from-scratch build. The 2026 docs-framework field is mapped, and so is hosting: Pages' built-in Jekyll can't meet the dark-mode brief on its own, while Starlight or VitePress deploy to Pages for $0 with a small Actions workflow. Zac leans towards Pages; the look gets picked in a visual bake-off. Content is in Zac's voice, trimmed, with a brief plug for Zac and We Right Code.

## Why it matters
A live docs site is a release goal in the intent, and Ang has a lot of concepts for a lean framework.
