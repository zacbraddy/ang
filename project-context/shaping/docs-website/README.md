# Documentation website

## Summary
A full docs site for users who've tried Ang and want to go deeper: usage, concepts, ambitions, motivations. Clean and simple, with light and dark mode following the system setting, using existing tools rather than a from-scratch build. The 2026 docs-framework field is mapped, and so is hosting: Starlight or VitePress deploy to Pages for $0 with a small Actions workflow, and Just the Docs runs on Pages' built-in build with system dark mode added in one line. Zac leans towards Pages. A visual bake-off narrowed the field to Starlight and VitePress, and an effort bake-off decided between them: VitePress was cheaper to change, but Zac chose **Starlight** for its looks and active maintenance, while VitePress 1.x sits frozen with an unscheduled v2 migration ahead. Starlight deploys to Pages through an Actions workflow. Colour palettes popular with dev-tool brands are mapped, and slate with a jade accent was used for the recolour test. Content is in Zac's voice, trimmed, with a brief plug for Zac and We Right Code.

## Why it matters
A live docs site is a release goal in the intent, and Ang has a lot of concepts for a lean framework.
