# Documentation website

## Summary
A full docs site for users who've tried Ang and want to go deeper: usage, concepts, ambitions, motivations. Clean and simple, with light and dark mode following the system setting, using existing tools rather than a from-scratch build. The 2026 docs-framework field is mapped, and so is hosting: Starlight or VitePress deploy to Pages for $0 with a small Actions workflow, and Just the Docs runs on Pages' built-in build with system dark mode added in one line. Zac leans towards Pages. The look is being picked in a visual bake-off, one candidate per session. Just the Docs and the native Pages themes are done: Zac finds the native themes cleaner and likes cayman best, but only minima has nav and none has search or dark mode. Content is in Zac's voice, trimmed, with a brief plug for Zac and We Right Code.

## Why it matters
A live docs site is a release goal in the intent, and Ang has a lot of concepts for a lean framework.
