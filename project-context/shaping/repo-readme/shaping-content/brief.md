# Brief

## Summary
Zac's spec (2026-11-13): a streamlined, simple, easy-to-follow README for people considering Ang, giving a high-level tour of the main concepts, the important commands and a quick start so they can get to trying it. It should **not** be an all-singing, all-dancing run-down of everything Ang does. It is kept separate from the docs website so it isn't held up by the site's research (agreed in /ideate, 2026-11-16).

## Requirements
- Main concepts, important commands, quick start.
- Brief mention of Zac and We Right Code, linking https://zackerthehacker.com. Present but not prominent.
- In Zac's voice (see voice and attribution).
- Describe the framework as the files implement it, not as the brain dump remembers it.
