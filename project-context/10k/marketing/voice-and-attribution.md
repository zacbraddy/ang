# Voice and attribution

## Summary
Ang's README and docs speak in Zac's own voice and credit him and We Right Code without fuss. Every fact here is Zac's statement of intent (ET 1, evidence tier 1: a primary source), given at bootstrap on 2026-11-13 and refined as the README and docs site shipped (2026-11-23). The website status is dated and will change. How to write a docs page in this voice is in the [docs voice guide](/project-context/10k/marketing/docs-voice-guide.md).

## Voice
- Zac's natural voice comes through prominently: conversational, opinionated, humorous, with a bit of whimsy.
- Trim his verbosity so readers aren't flooded, but keep the spirit and the way he explains ideas.
- Not corporate. Ang is one developer's project and doesn't pretend to the standards of React-scale repos.
- Avoid generic AI-generated design and copy.
- **README and docs site** use an emoji on the left of every heading.
- **Release notes** use this voice with an emoji per heading. Breaking changes and fixes stay plain-spoken. Upgrade guides have no voice, because an agent reads them (Zac's call, 2026-11-19; template in `releases/notes/README.md`).

## Attribution
- The wording is "Ang was developed by Zac Braddy and is sponsored by We Right Code", with Zac's name linking to **https://zackerthehacker.com** (his CV site). It sits at the foot of the README and in the footer of every docs-site page: easy to find, never pushed in readers' faces.
- Ang doubles as a portfolio piece for Zac and We Right Code.
- We Right Code has no website as of 2026-11-13, so there is nothing to link to for it yet.
