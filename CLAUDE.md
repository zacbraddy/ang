# The Ang repo

Everything under `src/` ships to people who install Ang in their own projects. Write it for them: it describes Ang as it runs in their repo, with their own `project-context/` library.

`project-context/README.md` here is a symlink to `src/project-context/README.md`, so this repo's library runs on the conventions that ship. Edits to it reach every install. Facts about the Ang repo itself (its ideas, parked work, epics, stories and release plans) live in this repo's own `project-context/` docs.
