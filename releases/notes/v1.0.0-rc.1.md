# 🚀 Ang v1.0.0-rc.1: the starter leaves the jar
Ang's first release candidate. Ang is a workflow framework for Claude Code that keeps you driving and your agents on task, instead of spiralling into edge cases until the project stalls under its own context (hence the name: *Avoid Navel Gazing*). This rc is the dress rehearsal for v1.0.0, so expect the odd rough edge and tell me when you hit one.

## 🧭 What's new
Everything. It's the first release. Here's what's in the box:

- **A stage workflow from idea to retro.** Brain dumps go in `raw/` and move through ideas, shaping, planning and execution to retro, with a skill for each step: `/ideate`, `/refine-ideas`, `/shape-ideas`, `/plan-epic`, `/break-down-epic`, `/write-story`, `/implement-story`, `/review-story`, `/retro`, and `/kill` for the ones that don't make it. `/trigger` parks an action until its moment comes (a story lands, a date passes, a file appears), so you don't have to remember it.
- **A project context library.** `project-context/` holds what your agents need to know about the project, technical and business, with `10k/` as current truth. A zero-dependency Node script keeps the indexes, state and links honest, and `/curate-10k` and `/curate-tags` stop it growing into a swamp.
- **Bootstrapping.** `/bootstrap-repo` seeds the library from a founding brain dump or by surveying an existing codebase. `/bootstrap-quality` sets up linting, formatting, tests, pre-commit hooks and CI. Opinionated engineering defaults ship too (right-size everything, TDD, DDD/Onion), and your repo's own conventions always win over them.
- **Make it yours.** `/tailor-ang` sets your name, workspace host, output style and a personal rule in gitignored local files, so teammates each get their own. Five output styles ship, with Partner In Crime as the default.
- **Optional features.** Switch them on in `ang.json`:
  - **intent:** a delivery-intent doc your retros check work against.
  - **streams:** parallel sessions, one branch and worktree each, with a mailbox that only sends with your say-so.
  - **host:** workspace cards in Orca that show where each stream is at.
- **Bend it as you go.** When the workflow gets in your way, `raise-workflow-improvement` writes it down and `/improve-workflow` makes the change. Your copy of Ang becomes *your* Ang.
- **Upgrades that respect your edits.** `/upgrade-ang` three-way merges each new release with your local changes and leaves the result unstaged for you to review.

## 🔀 What changes for you
- **Installing:** from your repo's root, with a clean working tree:
  ```sh
  curl -fsSL https://github.com/zacbraddy/ang/releases/download/v1.0.0-rc.1/install.sh | sh
  ```
  Then run `/bootstrap-repo` in Claude Code.
- **Your settings:** Ang merges its hooks, one permission and a default output style into `.claude/settings.json`. Your own keys are kept, and a copy of the original is saved as `settings.json.pre-ang`. `/tailor-ang` changes the output style.
- **Nothing is overwritten:** if a file Ang ships already exists in your repo, the install stops and lists it before touching anything.

🟢 Requires Node 26 or later.
