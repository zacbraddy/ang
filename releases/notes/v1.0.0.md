**🚀 Ang is here: the last software bender you'll ever need**

Ang (Avoid Navel Gazing) is a lean, opinionated framework for AI-assisted development in Claude Code. It stops your agents burning tokens until the ocean boils 🌊🔥, spiralling into edge cases and over-specifying everything until your project stalls, and gets them doing actual work instead. You drive; Ang assists. Don't like my opinions? Cool, it's yours now. Bend it.

### 📥 Install it
From the root of your project's git repo, with a clean working tree:

```sh
curl -fsSL https://github.com/zacbraddy/ang/releases/latest/download/install.sh | sh
```

Then open Claude Code in the repo and run `/bootstrap-repo`. It sets Ang up for your project, from your goals or from the code you already have, and finishes by tailoring Ang to you.

You'll need Claude Code, git, and Node.js 26 or later with npx. Ang runs on macOS and Linux. On Windows, run it inside WSL.

### ✨ What you get
- **The funnel.** Work flows `raw → ideas → shaping → planning → execution → retro`, one command per stage, each in a fresh session. Half-baked thoughts go in the top; well-understood epics and reviewed stories come out the bottom.
- **The context library.** Everything Ang knows about your project lives in `project-context/`, with `10k/` as the current truth. Docs are replaced, not hoarded, so every session loads only what it needs and agents stay sharp.
- **Workflow improvements.** Hit some friction? `/raise-workflow-improvement` records it and `/improve-workflow` has an agent bend Ang to fit. Ang isn't *this* repo; it's whatever *your* copy becomes.
- **Streams, if you want them.** 🌊 Parallel work in separate git worktrees, with a mailbox so your agents aren't furiously rowing in opposite directions. Plays nicely with [Orca](https://github.com/stablyai/orca) if you use it, and doesn't care if you don't.
