# 🚀 Ang v1.0.0-rc.2: second lap, same car
Ang's second release candidate. Almost nothing changed for you, and that's the point: this release exists to prove the upgrade path works for real, by taking an install from rc.1 to rc.2 with its local edits intact before v1.0.0 asks you to trust it.

## 🔀 What changes for you
- **Nothing you'll notice.** One code comment changed. Upgrade thresholds and behaviour are the same as rc.1.
- **Upgrading from rc.1:** run `/upgrade-ang` in Claude Code. It should take the fast route and leave the result unstaged for you to review.
- **Installing fresh:** from your repo's root, with a clean working tree:
  ```sh
  curl -fsSL https://github.com/zacbraddy/ang/releases/download/v1.0.0-rc.2/install.sh | sh
  ```
  Then run `/bootstrap-repo` in Claude Code.

🟢 Requires Node 26 or later.

## 🔗 Changes in this release
- [1210ea5](https://github.com/zacbraddy/ang/commit/1210ea5da3b610dacd11642d6a88dd1170b8515e): the upgrade route thresholds stay as they are until real upgrades say otherwise.
