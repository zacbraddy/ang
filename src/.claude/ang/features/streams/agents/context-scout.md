## Other streams
The user runs parallel streams, one branch per worktree. When the question plausibly touches work in another stream, `node .claude/scripts/ang-context-manager.mjs stream list` first and read the focus lines. Peek only at streams whose focus fits, read-only and without checking anything out:
- `git grep -n <term> <branch> -- project-context` to find docs
- `git show <branch>:project-context/<path>` to read one, Summary first
Label everything found this way with its stream, e.g. "(stream ideation, provisional)". Another stream's docs are in flight even under `10k/` until they merge to main.
